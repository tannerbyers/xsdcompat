# Support Policy

`xsdcompat` is an open-source project maintained on a best-effort basis.

## Community support

Use GitHub Issues for reproducible bugs and GitHub Discussions (if enabled) for questions, design discussion, and usage help.

Please include enough information to reproduce technical issues:

- `xsdcompat` version or commit;
- operating system and architecture;
- minimal sanitized old/new schemas;
- expected result;
- actual result;
- configuration relevant to the issue.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## No SLA

The open-source project does not currently provide:

- guaranteed response times;
- guaranteed fix times;
- 24/7 support;
- long-term support branches;
- regulatory/compliance certification;
- warranties beyond those stated in the Apache-2.0 license.

## Supported versions

Before 1.0, users should generally reproduce issues on the latest development release before reporting them.

After 1.0, this document will identify any actively supported release lines. Unless explicitly documented otherwise, only the current release line should be assumed supported.

## Enterprise use

Organizations are free to pin and internally qualify specific releases. A pinned release does not create a maintenance obligation for the upstream project.

The project's deterministic/offline design is intended to make internal qualification and long-term pinning practical, but users remain responsible for evaluating tool output within their own engineering and compliance processes.
